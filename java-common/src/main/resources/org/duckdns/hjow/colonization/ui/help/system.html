게임 시스템

정착지, 도시, 연구, 시설, 시민

게임 내에서 여러분은 정착지 하나를 운영하게 될 것입니다.
세이브 파일 하나 당 정착지 하나를 나타냅니다.
즉, 새 정착지를 개척한다는 것은 게임을 새로 시작하는 것과 같습니다.

정착지에는 예산 (돈), 연구, 도시가 존재할 수 있습니다.
예산(돈)과 연구는 정착지내 모든 도시가 공유해 사용한다는 의미입니다.

정착지에는 여러 도시가 존재할 수 있습니다. 조건이 맞으면 새 도시를 건설할 수도 있습니다.
처음 시작하면 도시 하나가 건설된 채로 시작합니다.
새 도시를 추가 건설하려면 상당한 예산이 필요하며, 최소 인구가 1000이 넘어야 합니다.

도시에는 물론 시민이 거주하며, 여러 시설이 도시에 건설됩니다.
게임 내에서 여러분이 주로 통제하는 것이 바로 이 시설로, 시설 건설, 증축, 철거함으로써 도시를 운영해 나가게 될 것입니다.

시설 중 연구가 가능한 시설이 존재하며, 화면 내 "시설" 탭에서 해당 시설을 찾아 연구를 진행할 수 있습니다.
마찬가지로, 생산이 가능한 시설이 존재하며, 화면 내 "시설" 탭에서 해당 시설을 찾으면, 상품/재료 생산이 가능합니다.

시설의 효율

시설이 잘 동작하려면, 전력과 근로자가 충분하여야 합니다.

일부 시설은 통신(네트워크) 가 필요한 경우도 있습니다.

도시가 충분히 커지면, 대중교통이 필요할 수 있습니다.
대중교통이 부족하면 일부 근로자가 시설로 통근하지 못하며,
해당 시설은 근로자가 부족하게 됩니다.
