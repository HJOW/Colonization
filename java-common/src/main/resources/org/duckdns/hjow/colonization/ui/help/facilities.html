시설

개요

사용 가능한 시설 목록들을 정리한 문서입니다.

시설의 경우, 전력 공급이 부족하거나 근로자 시민이 충분히 배치되지 않으면 효율이 급격히 떨어집니다.

근로자가 계속 부족한 경우, 시민이 출퇴근 가능하도록 대중 교통을 마련해야 할 수도 있음에 유념해 주세요.

연구 진행에 따라 새 시설이 갑자기 건설 가능해질 수 있습니다. 수시로 확인해 주세요.

일부 시설들은 사전 조건에 정확한 레벨이 기재되어 있지 않습니다. 또한, 일부 고급 시설들은 기재되어 있지 않습니다.

업그레이드 조건은 기재되어 있지 않습니다.
