Script API

개요

MOD 및 사용자 정의 시설 개발에 쓰이는 스크립트에서 사용할 수 있는 함수들입니다.
Colonization 게임 내 스크립트 엔진은
기본적인 자바스크립트 문법 (var, for, while, if, function 및 연산자) 를 동일하게 지원하지만,
웹과 node.js 에서 제공하는 기본 함수들이 지원되지 않습니다.
대신 다음과 같은 함수들을 사용하실 수 있습니다.

String(p1)
p1 값을 문자열로 강제 형 변환 합니다.
p1 에는 어떤 타입도 들어갈 수 있습니다.

Date(p1, p2)
p1 값을, 날짜를 나타내는 Date 타입 객체로 변환합니다.
p1, p2 에는 둘 다 문자열이 들어가야 하며,
p1 에는 날짜 데이터 부분, p2는 날짜 형식을 지정합니다.
예) Date("2025-10-22", "yyyy-MM-dd")

convertDateFromTimeMills(p1)
p1 숫자값을 날짜로 변환합니다. 1970년 1월 1일 0시 0분 0초 GMT 이후 흐른 시간을 밀리초 단위로 나타낸 숫자로 인식합니다.
p1 에는 양의 정수값이 들어가야 합니다.

today()
오늘 날짜를 나타내는 Date 객체를 반환합니다.

subtractDate(p1, p2)
p1, p2 모두 Date 타입 객체여야 합니다.
두 날짜의 차이를 계산해 Date 객체 형태로 반환합니다.

parseInt(p1)
p1 을 정수로 형 변환 합니다. 어떤 객체든 들어갈 수 있으나, 강제 문자열 형변환 시 정수 값이 나와야 합니다.

parseFloat(p1)
p1 을 부동소수로 형 변환 합니다. 어떤 객체든 들어갈 수 있으나, 강제 문자열 형변환 시 부동소수 값이 나와야 합니다.

list()
빈 List 객체를 만들어 반환합니다. 원소 여럿을 추가하거나 꺼내거나 제거할 수 있는 컬렉션입니다.

map()
빈 Map 객체를 만들어 반환합니다. 키-값 형태로 원소를 관리할 수 있는 컬렉션입니다.

isNull(p1)
p1 가 null 인지 확인합니다. null 이면 true 아니면 false 를 반환합니다.

getClassType(p1)
p1 객체의 클래스 타입을 확인하여 문자열로 반환합니다.

isEquals(p1, p2)
p1, p2 객체가 같은지 확인합니다. (해당 객체 내 equals 기능을 사용합니다.) 객체가 동일하면 같으면 true 아니면 false 를 반환합니다.

splitString(p1, p2)
문자열 p1 을 구분자 p2 로 나누어, 나온 문자열들을 List 에 담아 반환합니다.
p1, p2 둘 다 문자열이어야 합니다.

newJsonObject()
빈 Map 객체를 반환합니다.
단순 Map 과는 다르게, 컨텐츠 전체를 JSON 문자열로 변환할 수 있습니다.

newJsonArray()
빈 List 객체를 반환합니다.
단순 List 과는 다르게, 컨텐츠 전체를 JSON 문자열로 변환할 수 있습니다.

parseJson(p1)
p1 문자열을 JSON 문자열로 인식하여, 해석해 Map 혹은 List 객체로 반환합니다.

translate(p1)
다국어 번역 스트링 테이블을 통해 p1 문자열을 번역하여 반환합니다.

math_PI()
부동소수값으로 수학의 PI (3.14159...) 값을 반환합니다.

math_E()
부동소수값으로 수학의 자연상수 e (2.71828...) 값을 반환합니다.

math_abs(p1)
부동소수값으로 p1 의 절대값을 반환합니다.
p1 에는 부동소수 타입의 값이 들어갈 수 있습니다.

math_random()
0 ~ 1.0 사이의 부동소수값을 반환합니다.

math_acos(p1)

math_asin(p1)

math_atan(p1)

math_cbrt(p1)

math_ceil(p1)
p1 의 올림값을 부동소수로 반환합니다.

math_cos(p1)

math_sin(p1)

math_tan(p1)

math_exp(p1)

math_floor(p1)
p1 의 내림값을 부동소수로 반환합니다.

math_getExponent(p1)

math_log(p1)

math_log10(p1)

math_isNegative(p1)

math_isPositive(p1)

math_compare(p1, p2)

math_pow(p1, p2)

math_round(p1)
p1 의 반올림값을 부동소수로 반환합니다.

math_sqrt(p1)

math_toDegrees(p1)

math_toRadians(p1)

math_rint(p1)

math_bigInteger(p1)

math_bigDecimal(p1)

hash(p1, p2)
문자열의 해시(단방향 암호화)값을 구해 반환합니다. p1 에는 해시값을 구할 문자열이 들어가야 하며, p2 에는 해시 알고리즘이 문자열로 들어가야 합니다.
해시 알고리즘으로는 SHA-1, SHA-256 를 지원합니다.

encrypt(p1, p2, p3)
문자열을 암호화합니다. p1 에는 암호화할 문자열, p2 에는 암호 키, p3 에는 암호화 알고리즘이 문자열로 들어가야 합니다.
암호화 알고리즘으로는 DES, AES를 지원합니다.
암호 키는 해시 알고리즘으로 처리 후 사용되므로, 다른 프로그램과는 호환되지 않습니다.

decrypt(p1, p2, p3)
암호화된 문자열을 복호화합니다. p1 에는 암호화된 문자열, p2 에는 암호 키, p3 에는 암호화 알고리즘이 문자열로 들어가야 합니다.
암호화 알고리즘으로는 DES, AES를 지원합니다.
암호 키는 해시 알고리즘으로 처리 후 사용되므로, 다른 프로그램과는 호환되지 않습니다.

ui_create(p1)
UI 컴포넌트 객체를 생성해 반환합니다. p1 에는 생성할 객체 유형이 문자열로 들어가야 합니다.
객체 유형은 다음과 같습니다.

  • dialog : 대화상자, Java Swing 의 JDialog 에 대응
  • panel : 패널, Java Swing 의 JPanel 에 대응
  • tab : 탭 패널, Java Swing 의 JTabbedPane 에 대응
  • split : 구분 영역, Java Swing 의 JSplitPane 에 대응
  • label : 레이블, Java Swing 의 JLabel 에 대응
  • textfield : 텍스트필드, Java Swing 의 JTextField 에 대응
  • textarea : 텍스트 영역, Java Swing 의 JTextArea 에 대응
  • table : 테이블, Java Swing 의 JTable 에 대응
  • table_model : 테이블 데이터 모델, Java Swing 의 DefaultTableModel 에 대응
  • button : 버튼, Java Swing 의 JButton 에 대응

ui_createsByJson(p1)
JSON 문자열로 UI 를 한번에 구성할 수 있습니다. 그 최상단에 위치하는 패널 객체를 반환합니다.
리턴된 객체로 컴포넌트 내 구성된 소속 컴포넌트들을 ID값으로 찾아 액세스할 수 있습니다.
p1 에는 JSON 형식 문자열이 들어가야 합니다.

ui_scroll(p1)
p1 컴포넌트를 스크롤 영역으로 감쌉니다. Java Swing 의 JScrollPane 에 대응합니다.

alert(p1)
p1 문자열을 메시지로 출력합니다.

askInput(p1)
p1 문자열을 메시지로 출력하고 텍스트를 입력 받습니다. 받은 내용이 문자열로 반환되며, 취소 시 null 이 반환됩니다.
