연구

개요

사용 가능한 연구 목록들을 정리한 문서입니다.

"최소 N레벨 이상" 이 의미하는 것은, 해당 연구의 다음 레벨 업그레이드를 위해서는 사전 필요한 연구의 레벨이 N 이상이어야 함을 의미합니다. 이를테면, "화학" 연구를 위해서는, 기초 과학 레벨이 최소 6레벨 이상이어야 합니다.

"이 레벨의 N배 이상" 이 의미하는 건, 해당 연구의 다음 레벨 업그레이드를 위해서는 사전 필요한 연구의 레벨의 레벨이 N배 이상이어야 함을 의미합니다.
이를테면, "기초 생물학" 10 레벨에서, 다음 레벨로 업그레이드를 위해서는, 기초 과학과 기초 인문학 레벨이 각각, 10 × 1.2 = 12레벨 이상이어야 합니다.

"M 레벨부터 이 레벨의 N배 이상" 은, 위와 동일하나, 이 조건이 해당 연구의 레벨이 M 이상일 때부터 적용된다는 것을 의미합니다.

일부 연구들은 사전 조건에 정확한 레벨이 기재되어 있지 않습니다. 또한, 일부 고급 연구들은 기재되어 있지 않습니다.

기초 과학 (BasicScience)

기초 과학은 모든 연구의 기초가 되는 분야로, 물리학, 화학, 생물학 등의 기초 이론을 포함합니다.

  • 사전 조건 연구 : 없음
  • 기본 연구 시간 : 600 초 (레벨 마다 1.1배씩 증가)

기초 인문학 (BasicHumanities)

기초 인문학은 인간의 사고, 문화, 사회를 이해하기 위한 기초적인 이론과 개념을 포함합니다.

  • 사전 조건 연구 : 없음
  • 기본 연구 시간 : 600 초 (레벨 마다 1.1배씩 증가)

기초 생물학 (BasicBiology)

기초 생물학은 생명체의 구조, 기능, 성장, 진화 등을 연구하는 분야로, 생물학의 기초 이론을 포함합니다.

  • 사전 조건 연구 : 기초 과학 (이 레벨의 1.2배 이상), 기초 인문학 (이 레벨의 1배 이상)
  • 기본 연구 시간 : 600 초 (레벨 마다 1.1배씩 증가)

기초의학 (BasicMedicalScience)

기초의학은 의학의 기초 이론과 원리를 포함하며, 인체 해부학, 생리학, 생화학 등의 기초 과목을 다룹니다.

  • 사전 조건 연구 : 기초 과학 (이 레벨의 3배 이상), 기초 생물학 (이 레벨의 2배 이상), 기초 인문학 (이 레벨의 1배 이상)
  • 기본 연구 시간 : 900 초 (레벨 마다 1.1배씩 증가)

공학기초 (BasicEngineering)

공학기초는 공학의 기초 이론과 원리를 포함하며, 기계, 전기, 전자, 컴퓨터 공학 등의 기초 과목을 다룹니다.

  • 사전 조건 연구 : 기초 과학 (이 레벨의 2배 이상), 기초 인문학 (30레벨부터 이 레벨의 1배 이상)
  • 기본 연구 시간 : 900 초 (레벨 마다 1.1배씩 증가)

화학 (Chemical)

화학은 물질의 성질, 구조, 변화 및 상호작용을 연구하는 과학 분야입니다.

  • 사전 조건 연구 : 기초 과학 (최소 6레벨 이상, 이 레벨의 5배 이상)
  • 기본 연구 시간 : 600 초 (레벨 마다 1.1배씩 증가)

에너지 (EnergyTech)

에너지 연구는 에너지의 생성, 변환, 저장 및 사용에 관한 과학적 원리를 탐구합니다.

  • 사전 조건 연구 : 기초 과학 (이 레벨의 1.2배 이상), 공학기초 (이 레벨의 1배 이상)
  • 기본 연구 시간 : 600 초 (레벨 마다 1.1배씩 증가)

군사학 (MilitaryTech)

군사학은 전쟁, 군사 전략, 전투 기술 및 군사 조직에 관한 과학적 원리를 탐구합니다.

  • 사전 조건 연구 : 기초 과학 (이 레벨의 4배 이상), 공학기초 (이 레벨의 2배 이상), 기초 인문학 (20레벨부터 이 레벨의 1배 이상)
  • 기본 연구 시간 : 800 초 (레벨 마다 1.1배씩 증가)

신금속공학 (NewMetals)

신금속공학은 새로운 금속 및 합금의 개발, 특성 분석 및 응용을 연구하는 분야입니다.

  • 사전 조건 연구 : 기초 과학 (이 레벨의 5배 이상), 화학 (이 레벨의 2배 이상), 공학기초 (최소 10레벨 이상, 이 레벨의 7배 이상)
  • 기본 연구 시간 : 600 초 (레벨 마다 1.2배씩 증가)

기초건축학 (BasicBuildingTech)

기초건축학은 건축의 기초 이론과 원리를 포함하며, 건축 설계, 구조 공학, 재료 공학 등의 기초 과목을 다룹니다.

  • 사전 조건 연구 : 기초 과학 (이 레벨의 3배 이상), 공학기초 (이 레벨의 2배 이상), 신금속공학 (최소 10레벨 이상, 25레벨부터 이 레벨의 1배 이상), 기초 인문학 (15레벨부터 이 연구의 1배 이상)
  • 기본 연구 시간 : 600 초 (레벨 마다 1.1배씩 증가)

광학 (LightTech)

광학은 빛의 성질, 행동 및 상호작용을 연구하는 과학 분야입니다.

  • 사전 조건 연구 : 기초 과학 (최소 10레벨 이상, 이 레벨의 5배 이상), 공학기초 (최소 6레벨 이상, 이 레벨의 3배 이상), 에너지 (이 레벨의 1배 이상)
  • 기본 연구 시간 : 600 초 (레벨 마다 1.2배씩 증가)
