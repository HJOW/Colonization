정책

개요

사용 가능한 정책 목록들을 정리한 문서입니다.

정책은, 도시에서 시행하여 도시 내에서 특수 효과를 누릴 수 있는 시스템으로,
시행 시, 게임 내 시간으로 매월 비용이 발생합니다.
사전 연구가 존재하며, 해당 연구를 지정 레벨 이상 연구해야 시행이 가능합니다.

일부 고급 정책들은 기재되어 있지 않습니다.

발전 고효율 촉매 (PowerEfficiencyProtocol)

전력 생산 시설에서, 비용이 더 나가지만 더 효율이 좋은 촉매를 사용합니다.

  • 기본 월간 비용 : 100000
  • 추가 월간 비용 : 발전 시설의 유지비의 100분의 1, 모든 발전 시설 합산
  • 사전 조건 연구 : 에너지 (EnergyTech) 3레벨 이상
  • 효과 : 모든 발전 시설의 효율이 1.2배 상승합니다. 이 효율 상승치는 에너지 (EnergyTech) 레벨이 높으면 더 높아집니다.

출산 장려 정책 (FertilityPromotionPolicy)

출산 장려 캠페인을 시행합니다.

  • 기본 월간 비용 : 100000
  • 추가 월간 비용 : 시민 당 5
  • 사전 조건 연구 : 기초 인문학 (BasicHumanities) 5레벨 이상
  • 효과 : 출산률 보너스가 1.3배 상승합니다. 기초 인문학 (BasicHumanities) 레벨이 높으면 더 높아집니다.
