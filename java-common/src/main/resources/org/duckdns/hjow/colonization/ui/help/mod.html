MOD

개요

게임 내 화면 UI 로 만족할 수 없다면, MOD를 개발하여 직접 UI를 추가할 수 있습니다.
MOD는 자바 기반 MOD 와, 스크립트 기반 MOD 를 지원하며,
이 도움말에서는 스크립트 기반 MOD에 대해서만 설명합니다.

게임 세이브 디렉토리

Windows 운영 체제의 경우, "사용자홈폴더" 는 다음과 같은 형태를 가집니다. 

C:\Users\[사용자이름]\

게임 내 세이브와 설정 등은 다음 디렉토리에 저장됩니다.
(이를 "COL디렉토리" 라고 하겠습니다.) 

[사용자홈폴더]\.colonization\

스크립트 기반 MOD

자바스크립트 문법 코드를 작성하여 개발할 수 있는 MOD 입니다.
다음 디렉토리에 파일을 작성하여 스크립트 MOD를 개발할 수 있습니다. 

[COL디렉토리]\scripts\mods\

파일은 js 확장자의 텍스트 파일로, 캐릭터 인코딩은 UTF-8 을 사용해야 합니다.
파일 안에서 다음과 같은 함수들을 구현해야 합니다.

init(panel)
MOD 초기화 시 호출되는 함수입니다. MOD가 화면에 처음 나타날 타이밍에 호출됩니다.
panel 매개변수에는 java Swing 기반 JPanel 객체가 들어옵니다.
JPanel 에 대해서는 https://docs.oracle.com/javase/8/docs/api/javax/swing/JPanel.html 를 참고해 주세요.

getName()
MOD 의 이름을 반환해야 하는 함수입니다.

getDescription()
MOD 의 설명 문구를 반환해야 하는 함수입니다.

getLocation()
MOD 의 배치 위치 코드를 정수로 반환해야 하는 함수입니다. 현재는 0 만 허용됩니다.

refresh(panel, cycle, colony, manager)
화면이 갱신될 때 같이 호출되는 함수입니다.
이 곳에서 정착지에 대한 정보를 화면에 출력하면 됩니다.
panel 매개변수에는 init(panel) 함수와 동일한 JPanel 객체가 들어옵니다.
cycle 매개변수는 정수 값으로, 게임 내 시간으로 1초 당 1씩 증가합니다.
colony 매개변수에는 정착지 정보가 JSON 형태로 들어있습니다. (단, 읽기 전용 MOD가 아닌 경우, 정착지 객체 자체가 들어옵니다.)
manager 매개변수에는 게임 클라이언트 자체를 다루는 객체가 들어있습니다. 일부 기능이 제한되어 있습니다.

dispose(panel)
게임이 종료될 때 호출되는 함수입니다.
panel 매개변수에는 init(panel) 함수와 동일한 JPanel 객체가 들어옵니다.

isReadOnly()
읽기 전용 MOD 여부를 true / false 로 반환해야 하는 함수입니다.
되도록이면 true 를 사용해 주세요.
false 사용 시, 해당 MOD를 사용해 플레이한 정착지는 인증이 해제됩니다.
대신, false 사용 시 refresh(panel, cycle, colony, manager) 함수의 colony 매개변수로 정착지 객체 자체에 액세스가 가능해집니다.
