※ 개인정보 처리방침

 * 로컬 모드 (오프라인 모드)

 로컬 모드에서는 어떤 개인정보도 수집하지 않습니다.
 네트워크로 통신 시, 다음 목적으로만 통신하며,
 이 경우에도 개인정보는 전송되지 않습니다.
  - 공지사항 확인
  - 실행에 필요한 Java Runtime (JRE) 다운로드
  - 새 버전 확인 및 다운로드

 * 웹 모드

 웹 모드에서는 사용자 ID, 비밀번호 해시값 (단방향 암호화),
 이름 (닉네임 가능), 이메일 주소를 계정 정보로서 입력받아
 수집합니다.
 
 이는 계정 생성 (가입) 시 사용자 본인이 직접 입력하여야
 하며, 자동으로 수집되지는 않습니다.
 
 개인정보 처리 목적은 다음과 같습니다.
  - ID, 비밀번호 해시값 - 로그인 인증 목적
  - 이름(닉네임) - 화면 출력
  - 이메일 주소 - 고지해야 할 사항이 발생한 경우 메일 발송
 
 개인정보 보호 기간은 가입 후 탈퇴 시 까지입니다.
 탈퇴 기능은 구현 예정입니다.
 탈퇴 기능 사용 시 계정 및 그에 속한 개인정보는 모두 삭제
 되도록 개발할 예정입니다.
 
 현재 웹 모드는 구현이 완료되지 않아 플레이가 불가능하므로
 이 개인정보의 사용처는 확정된 사항이 없습니다.
